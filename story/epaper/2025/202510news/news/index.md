# 2025 OCT 開放科技新聞摘要

## 2025-10-07 - Linux Foundation - React Foundation 將成立

The Linux Foundation 宣布將成立 React Foundation，作為 React、React Native 與相關專案的新中立組織載體，讓該專案在開放性、創新性、社群主導上得以維持與發展。 
- 原文：[Linux Foundation Announces Intent to Launch the React Foundation](https://www.linuxfoundation.org/press/linux-foundation-announces-intent-to-launch-the-react-foundation)

## 2025-09-23 — 開放知識基金會（OKFN）- 呼籲科技與公共利益的平衡

開放知識基金會（OKFN）發布新指南《The Tech We Want - Read This Before You Build》，以其 20 年倡議經驗，提出開發公共利益科技前，團隊應思考的 8 大核心問題，強調簡單、耐用、社群共創和以負責任的方式整合人工智慧（integrate AI responsibly）整合。內容包含真實案例與自評工具，呼籲技術團隊「慢一點、做小一點、更傾聽」，以打造真正有用且包容的數位工具。  
- 原文：[Our New Field Guide: ‘The Tech We Want - Read This Before You Build](https://blog.okfn.org/2025/09/23/our-new-field-guide-the-tech-we-want-read-this-before-you-build/)

## 2025-09-19 — 歐洲自由軟體基金會（FSFE）- 持續維持數位市場公平競爭與使用者選擇權 

歐洲自由軟體基金會（FSFE）發布聲明表示將在 10/21 以第三方身分（intervener）參與一起與 Apple 與歐盟執行（DMA）相關之訴訟聽證會，這場訴訟關係到 Apple Store 是否要依照 DMA 的規定開放第三方應用市場。  
- 原文：[DMA litigation: the FSFE takes part in court hearing in Apple vs Commission case](https://fsfe.org/news/news.en.html)

## 2025-09-18 — Access Now — 考試期間不要斷網 #NoExamShutdown

考試期間斷網可以遏止學生作弊？ Access Now 與多個組織正發起 #NoExamShutdown 運動，呼籲中東北非各國停止此做法，保障教育與數位人權。
- 原文：[#NoExamShutdown: lessons for the new academic year](https://www.accessnow.org/no-exam-shutdown-new-academic-year/)
