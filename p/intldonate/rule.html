國際會議獎助計畫

2026 年度・開放文化基金會・鼓勵台灣青年與國際社群交流

← 回專案頁 計畫申請辦法 立即報名 我要推薦會議

為鼓勵台灣更多開放文化貢獻者與國際社群交流，開放文化基金會（OCF）特設立「國際會議獎助計畫」，支持台灣行動者參與國外開放科技、開源、數位人權、開放資料、開放政府相關國際活動之出訪旅費。

一、OCF 建議活動（優先徵集）

活動日期地點
Open Tech Week（含 Mozilla Festival）2026/10/28 – 10/30巴賽隆納，西班牙
Open Source Summit Japan2026/12/7 – 12/9東京，日本
Open Source Compliance Summit Japan2026/12/10 – 12/11東京，日本

Open Tech Week 為巴塞隆納市政府主辦之城市級開放科技週，Mozilla Festival 是期間內的旗艦活動，有正式 CFP 徵稿機制。

建議活動資訊

Open Tech Week（含 Mozilla Festival）

時間：2026.10.28 – 2026.10.30

地點：巴賽隆納，西班牙（Recinte Fabra i Coats）

官網：https://www.mozillafoundation.org/en/festival/

Open Tech Week 是巴塞隆納市政府主辦的城市級開放科技週，Mozilla Festival（MozFest）是其中的旗艦活動，也是 Mozilla 基金會與巴塞隆納市政府簽署三年合作（至 2027 年）的年度盛會。本屆主題為「Wilding」，探討如何鬆綁僵化的系統，讓社群與科技得以像生態系一樣自然演化，活動涵蓋議題對談與實作工作坊，有正式 CFP 徵稿機制。

Open Source Summit Japan

時間：2026.12.7 – 2026.12.9

地點：東京，日本（Toranomon Hills Forum）

官網：https://events.linuxfoundation.org/open-source-summit-japan/

Open Source Summit Japan 是日本規模最大的開源技術會議，由 Linux Foundation 主辦，整合 LinuxCon、ContainerCon、CloudOpen 三場會議於一體，議程涵蓋 Linux 核心、雲原生技術與開源 AI 等主題，可直接與全球維護者及社群領袖交流。2026 年將與 ELC Asia、Automotive Linux Summit 同場地共同舉辦。

Open Source Compliance Summit Japan

時間：2026.12.10 – 2026.12.11

地點：東京，日本

官網：https://events.linuxfoundation.org/open-compliance-summit/

Open Source Compliance Summit（Open Compliance Summit）由 OpenChain 專案主辦，聚焦開源授權、資安與出口管制合規等議題。主要對象為 Linux Foundation 會員與受邀者，適合關注企業與政府開源合規治理的申請人參與或投稿，實際入場資格請以主辦單位公告為準。

自訂活動也歡迎申請

除上述建議活動外，也開放申請人自行提議參與的國際活動，申請時須額外說明：

  1. 參與原因（議程主題、投稿內容等）
  2. 與 OCF 的相關性（活動主題如何對應 OCF 關注領域）
  3. 回饋社群規劃（返台後如何回饋台灣社群）

二、申請資格

  • 年滿 18 歲
  • 具中華民國國籍且常住台灣（近一年超過 183 天）
  • 通中英文，不需另有翻譯人員協助者
  • 具開源社群、網路自由、數位人權、開放資料、開放政府等相關經驗或關注者尤佳
  • 不限學生身分，一般社會人士／在職工作者亦歡迎申請

三、申請流程

  1. 於活動開始前 1 個月提出申請
  2. 填妥報名表單（見「立即報名」頁）
  3. OCF 內部隨到隨審，收到申請後 1 個月內通知審查結果
  4. 錄取者簽署權利義務同意書，並提供機票／住宿訂位證明後，即可申請第一期撥款

四、獎助內容與金額

單人獎助上限 新臺幣 50,000 元，採實報實銷制，涵蓋機票、住宿、活動報名費。

分兩期撥款

期別比例／金額撥付條件
第一期60%（上限 30,000 元）錄取並簽署同意書後，憑機票／住宿訂位證明申請撥付
第二期40%（上限 20,000 元）完成活動參與、回饋分享會、心得文章，並提交核銷單據審核通過後撥付

實際撥款金額依核銷單據總額核實，不得超過各期上限，兩期合計不超過 50,000 元／人。

五、受獎助者義務

  1. 活動結束後兩個月內舉辦一場公開、免費的經驗分享會
  2. 提供活動參與照片／截圖至少 3 張，分享會照片至少 1 張
  3. 活動結束後兩週內於網路公開平台（部落格、GitHub 等，不含純 Facebook）發表心得文章，以創用 CC 授權釋出
  4. 分享會、心得文章需註明「本次出訪由 OCF 國際會議獎助計畫支持」
  5. 核銷：提供單據正本、文章連結、參與截圖、簽署領據

本頁內容為 2026 年度徵選辦法之公告版本，實際執行細節（如審件委員、核銷單據格式等）以 OCF 內部最終通知為準，若有調整將另行公告。如有疑問歡迎透過報名表單留言詢問。
